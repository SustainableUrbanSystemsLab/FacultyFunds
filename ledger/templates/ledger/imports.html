Nothing is saved until you confirm the preview. Names and employee IDs are replaced with initials and a keyed hash as soon as the file is read; the file itself is never stored.

What to export

  • Workday: an expense report list or expense lines report (e.g., Find Expense Reports, or a report with a Worktags column) → Export to Excel.
  • OneUSG Connect: Manager Self Service → Commitment Accounting reports such as Payroll Expenses Detail → download to Excel or CSV. PeopleSoft “Excel” files that are really web pages work too.
  • Anything else: any spreadsheet with a date and amount per row, or one column per month.

The first time you import a layout, you'll match columns. The mapping is saved and reused automatically for files with the same columns.
